# Quy tắc tài liệu dự án

Tất cả thông tin về dự án phải được lưu trong một file duy nhất: `CLAUDE.md` ở thư mục gốc của workspace (`next-app/CLAUDE.md`).

Điều này bao gồm:
- Giới thiệu dự án, mô tả tính năng
- Công nghệ, thư viện, ngôn ngữ sử dụng
- Cấu trúc thư mục
- Thông tin đăng nhập, credentials
- API routes, database models
- Hướng dẫn cài đặt và chạy dự án
- Design system, bảng màu, typography
- Danh sách trang và routes
- Lưu ý quan trọng, quy tắc nghiệp vụ
- Bất kỳ thông tin nào liên quan đến dự án

Khi cần cập nhật thông tin dự án, LUÔN cập nhật vào `CLAUDE.md`. Không tạo file tài liệu mới.
